THE PROBLEM

How can a mobile experience support a learner’s next step?

Learning content and practice belong in the same journey. PyWhiz brings Python-learning videos, quizzes, profiles and synchronized progress into a mobile app, with the learner’s workflow informing the documented product approach.

THE APPROACH

From question to artifact.

  1. 01

    Start with the learner

    Surveys and user workflows inform a user-centered approach to the learning experience, giving the team a way to connect learner needs with the app’s flow.

  2. 02

    Connect learning and practice

    The app combines learning videos with quizzes and progress tracking. Together with a learner profile, these capabilities form a connected learning flow at the project level.

  3. 03

    Build a mobile system

    React Native and TypeScript provide the mobile application foundation, with Expo and Firebase supporting the stack. The project brings user-centered design and system thinking into the same application.

DELIVERED ARTIFACT

What the project leaves behind.

A mobile Python-learning app created with Jason Jahja, alongside research, user workflows and system documentation. The app brings videos, quizzes, profiles and synchronized progress into one learning experience.

PyWhiz

A Python-learning mobile app that connects videos, quizzes and synchronized progress.

Role

Team contributor

Tools & methods

React Native · TypeScript · Firebase · Expo

View on GitHub ↗

Mobile app code and project documentation

Problem

Learners needed a connected mobile workflow for watching lessons, practicing Python and returning to their progress.

My contribution

Collaborated on the mobile learning app.

Approach

  1. Understand learners

    The team documented surveys and user workflows to inform the learning experience.

  2. Connect the journey

    Videos, quizzes, profiles and synchronized progress form the app’s learning flow.

  3. Build for mobile

    React Native and TypeScript power the app, with Firebase and Expo supporting the mobile stack.

Delivered

A collaborative mobile application with supporting research, user workflows and system documentation.

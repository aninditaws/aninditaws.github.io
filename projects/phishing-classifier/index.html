THE PROBLEM

What needs to happen before a URL reaches a classifier?

Classifying phishing URLs requires a path from the dataset to model-ready inputs. This team assignment explores K-nearest neighbors and Gaussian Naive Bayes, with separate contributions for preparing the data and building the models.

THE APPROACH

From question to artifact.

  1. 01

    Prepare the data

    My assigned contribution begins with cleaning and preprocessing the data. This is the preparation work that makes the dataset usable in the classification workflow.

  2. 02

    Assemble the pipeline

    I assembled the pipeline connecting the preparation stages with the team’s classification work, making the separate parts of the assignment work together.

  3. 03

    Connect the team’s methods

    Teammates implemented KNN and Gaussian Naive Bayes. Bringing their models together with the preparation stages creates a shared classification workflow, with each contributor’s work connected through the pipeline.

DELIVERED ARTIFACT

What the project leaves behind.

A prepared dataset and an assembled classification pipeline connecting preprocessing with the team’s KNN and Gaussian Naive Bayes models.

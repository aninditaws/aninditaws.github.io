Individual Project · Data & Algorithms

Indonesian Stock Data ETL

Turning company records into a dataset for financial analysis.

Background

An individual data project to turn Indonesian company and financial records into a dataset for sector and historical comparisons.

Key Decisions

Build a Collection-To-Storage Pipeline

Clean and transform company records with Python and Pandas, store the structured data in PostgreSQL, and chart sector and historical comparisons.

Results

A collection-to-storage pipeline with charts of sector market capitalization and profit trends. The visuals show recorded project data rather than a live market feed.

Contribution

I collected records from IDN Financials, cleaned and transformed them with Python and Pandas, and modeled the data in PostgreSQL.

  • Python
  • Pandas
  • PostgreSQL

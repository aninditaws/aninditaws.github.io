Data engineering · Personal project

Indonesian Stock Data ETL

A Python pipeline that turns Indonesian company and financial data into a structured PostgreSQL dataset.

Role

Author

Tools & methods

Python · Pandas · PostgreSQL

View on GitHub ↗

Code, schema and project documentation

Problem

Company profiles, sector information and historical profitability data needed a consistent structure before they could be analyzed together.

My contribution

Data collection, transformation and database modeling.

Approach

  1. Collect

    Scraped company, sector, market-cap and historical profitability information from IDN Financials.

  2. Transform

    Cleaned and prepared the source data with Python and Pandas.

  3. Model

    Stored the transformed data in PostgreSQL and documented the relational schema and ERD.

Delivered

A reusable ETL pipeline and relational dataset, with a documented schema for further analysis.

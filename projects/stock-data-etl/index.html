THE PROBLEM

How can scattered financial information become a usable dataset?

Company profiles, sectors, market capitalization and historical profitability describe different parts of the same market. This project brings information from IDN Financials into a consistent relational structure for further analysis.

THE APPROACH

From question to artifact.

  1. 01

    Collect the source data

    Scrape Indonesian company, sector and market-cap information alongside historical profitability data from IDN Financials. The collection brings company-level information and historical data together for the next stage.

  2. 02

    Clean and transform

    Use Python and Pandas to prepare the scraped information for storage. This transformation step connects the source information to the structure expected by the database.

  3. 03

    Model for reuse

    Store the prepared data in PostgreSQL using a relational model. The documented schema and entity-relationship diagram make the structure available for others to understand and build on.

DELIVERED ARTIFACT

What the project leaves behind.

A Python ETL pipeline, a relational PostgreSQL dataset, and documented schema/ERD. Together, these artifacts turn scraped financial information into a structured foundation for analysis.

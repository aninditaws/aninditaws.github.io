Background

A bioinformatics research prototype exploring DNA variants associated with neurodegenerative diseases.

Project scope

The pipeline covers sequence-quality checks, read alignment, variant calling and filtering with Python, BWA, Samtools and BCFtools.

Result

A computational workflow for further research. The gallery uses dummy variant records; the full pipeline has not been reverified and is not a validated diagnostic tool.
